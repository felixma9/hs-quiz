Class icons: 128px WebP files named after the class, in capitals
(DRUID.webp, DEMONHUNTER.webp, NEUTRAL.webp, ...). They are shown at 42px
at most, so 128px stays sharp on 3x phone screens. A class without a file
falls back to the built-in badge in the class picker.

Only add images you have the right to use on a public site.
