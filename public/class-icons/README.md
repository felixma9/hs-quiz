Optional class icons for the class picker. Nothing ships here by default.

Add a PNG named after the class, in capitals: DRUID.png, HUNTER.png, MAGE.png,
PALADIN.png, PRIEST.png, ROGUE.png, SHAMAN.png, WARLOCK.png, WARRIOR.png,
DEMONHUNTER.png, DEATHKNIGHT.png, NEUTRAL.png. Square images work best.
Classes without a file keep the built-in badge.

Only add images you have the right to use on a public site.
